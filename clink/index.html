01 / THE CHALLENGE

How could design quality improve
without slowing the team down?

AI-assisted coding made it possible to build functional product pages quickly. As the merchant portal expanded, the challenge was to give those pages a consistent Clink identity without redesigning each one individually.

PAGE BY PAGE

Build → Redesign → Implement

Repeat the design handoff for each new screen.

PATTERN BY PATTERN

Design the patterns → Extend

Make recurring design decisions reusable.

02 / SELECT FOR COVERAGE

Three screens.
Different structures. One language.

The starting point was a small set of representative screens, chosen to cover different interface structures.

DATA-HEAVY

Core Metrics

Establish hierarchy across summary metrics, charts, filters and transaction details.

LIST-HEAVY

Rules

Bring search, classification, status and row actions into a consistent table structure.

CONFIGURATION-HEAVY

Routing Rules

Extend the language to grouped rules, nested flows and default states.
